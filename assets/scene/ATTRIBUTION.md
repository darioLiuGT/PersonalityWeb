# Waterfront scene assets

This website bundles four low-poly GLB files from Kenney asset packs:

- `kenney-building-a.glb` and `kenney-building-e.glb` — City Kit (Commercial)
- `kenney-road.glb` — City Kit (Roads)
- `kenney-palm.glb` — Nature Kit

Source: [Kenney](https://kenney.nl/). License: [CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/).

The scene composition and all procedural lighting, water, skyline, and animation code in
`waterfront-scene.js` are original to this portfolio.
